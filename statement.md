# Project Statement

## Problem Statement

Users often need strong, unpredictable passwords for accounts and applications. Manually creating passwords can result in short, repetitive, or predictable choices. The project provides a terminal-based Python solution that securely generates passwords according to user-selected rules and gives a basic strength assessment.

## Scope

The project focuses on secure random password generation and password-strength analysis. It accepts user-defined length and character categories, supports multiple password generation, validates input, and provides an estimated entropy value.

The project intentionally avoids storing generated passwords or transmitting them to external services.

## Target Users

- Students learning Python.
- Users who need quick random passwords.
- Developers who need temporary test credentials.
- Users who want a basic password-strength check from the terminal.

## High-Level Features

1. Interactive password generation.
2. Command-line password generation.
3. Custom length and character categories.
4. Multiple password generation.
5. Password strength classification.
6. Entropy estimation.
7. Input validation and error handling.
8. Automated unit testing.
